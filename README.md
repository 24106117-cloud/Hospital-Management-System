
# Hospital Management System

## Project Overview
Hospital Management System is a Java-based desktop application developed to manage hospital operations efficiently. It helps manage patient records, doctor information, appointments, and billing details.

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- Apache NetBeans
- MySQL Workbench

## Modules

### 1. Patient Management
- Add Patient
- View Patients
- Update Patient
- Delete Patient

### 2. Doctor Management
- Add Doctor
- View Doctors
- Update Doctor
- Delete Doctor

### 3. Appointment Management
- Book Appointment
- View Appointments
- Update Appointment
- Delete Appointment

### 4. Billing Management
- Add Bill
- View Bills
- Update Bill
- Delete Bill

## Features
- User-friendly graphical interface
- MySQL database connectivity
- CRUD operations
- Input validation
- Dashboard navigation

## How to Run
1. Open the project in Apache NetBeans.
2. Create the required MySQL database and tables.
3. Configure the database connection.
4. Add the MySQL JDBC driver if required.
5. Run `Dashboard.java`.
